Examples
========

Examples 01–18 are runnable scripts with their figures and printed output.
Follow :doc:`/tutorial` for the recommended order, prerequisites, and what to
inspect.

Build the gallery locally with ``bash scripts/build_gallery.sh``. Read the Docs
shows the committed outputs and does not run the examples.
